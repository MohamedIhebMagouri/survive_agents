# PREVIEW UI

## Routes

- `/landing` or `/`
- `/login`
- `/dashboard`
- `/simulation-room`
- `/logout`

## Run

```bash
npm install
npm run dev
```

## Suggested Demo Flow

1. Start from the landing page.
2. Click **Access platform** or **Login**.
3. Use **Sign in** to open the dashboard.
4. Open **Start simulation** or **Join Active Room**.
5. Finish with the **Logout** page.

## Important

This is a static demonstration UI based on the requested Survive presentation flow. It does not include backend logic, API calls, database integration or real authentication.
